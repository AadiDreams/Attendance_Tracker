# Attendance_Tracker

This is a mobile-friendly attendance app created from the supplied Excel student list (57 students).

Rules:
- Periods 1–3: at least 2 Present = first half present.
- Periods 4–5: exactly 2 Present = second half present.
- Both halves = 1 day.
- One qualifying half = 0.5 day.
- Neither = 0.
- Monthly working days = dates saved as attendance records.

Data is stored locally in the browser and can be exported as JSON backup.

Deployment: GitHub Pages, Netlify, Cloudflare Pages, or any HTTPS static host.
